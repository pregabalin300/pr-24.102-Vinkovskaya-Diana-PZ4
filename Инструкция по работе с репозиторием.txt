Краткая инструкция по работе с репозиторием:

1. Для получения локальной копии проекта используйте команду:
   git clone https://github.com/ваш-логин/ваш-репозиторий.git

2. Перед началом работы всегда обновляйте локальную версию:
   git pull origin main

3. Для создания новой ветки и перехода в нее:
   git checkout -b имя-новой-ветки

4. После внесения изменений добавьте файлы и закоммитьте их:
   git add .
   git commit -m "Описание изменений"

5. Отправьте изменения на удаленный сервер:
   git push origin имя-ветки
